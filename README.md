# 雲熙驗單打包助手｜Woodworking Order Packing Assistant

> 為木工板材工廠的驗單與分包流程設計的 Windows 桌面工具，將掃碼、板件重量計算、分包與作業提示整合在一起。

## 背景與要解決的問題

板件出貨需要核對訂單、估算包裹重量，且工作現場可能持續掃入新料件或臨時調整包裝上限。手動試算與分包容易增加等待時間，也不利於中斷後續作業。此工具試圖把計算和驗證放進同一個工作畫面。

## 核心功能

- **XML 訂單匯入：** 解析既有雲熙格式，包含常見的欄位差異與編碼處理。
- **重量估算：** 根據板材長、寬、厚與密度參數計算個別板件重量；特定厚度可套用獨立參數。
- **分包建議：** 以貪婪式裝箱策略，依設定的每包重量上限安排板件；上限異動後可重新計算。
- **掃碼作業：** 搭配以鍵盤輸入模式運作的 USB 條碼掃描槍，協助核對處理狀態。
- **語音提示：** 透過非同步文字轉語音提醒成功、重複或錯誤事件，減少持續盯著畫面的需求。
- **狀態保存：** 匯出處理中的掃碼／分包資訊，方便下一次繼續。

## 架構與技術

| 模組 | 職責 |
| --- | --- |
| `main.py` | Tkinter 視窗、操作事件、語音提示與流程協調 |
| `calculator.py` | 尺寸、密度、重量和分包計算 |
| `data_manager.py` | XML 讀寫、設定與資源路徑 |

**技術棧：** Python · Tkinter · XML · threading · pyttsx3；可使用 PyInstaller 封裝為 Windows 執行檔。

## 如何執行

```bash
python -m pip install pyttsx3
python main.py
```

實際部署還需使用符合現場作業格式的 XML 檔與設備驗證。若要封裝可攜版，可另行使用 PyInstaller 並檢查資源路徑。

## 面試展示重點

1. **實務流程分析：** 將生產現場驗單需求分解成資料匯入、計算引擎與掃碼確認。
2. **演算法取捨：** 貪婪分包速度快，但不保證全域最少包數；可討論更佳裝箱策略的成本。
3. **舊格式整合：** 與既有 XML 和實際條碼設備相容，比只寫新格式更重要。
4. **操作性：** 非阻塞語音提醒與狀態保存，改善現場使用體驗。

## 使用限制

重量準確度取決於尺寸、材料密度及原始訂單資料；分包建議不取代包裝安全檢查。本專案未聲稱對所有雲熙版本與設備皆完成驗證。
